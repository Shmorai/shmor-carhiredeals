# CarHireDeals (carhiredeals.shmor.ai)

A Shmor marketplace (shared rules in `../../CLAUDE.md`): its own brand, design and SEO. Global car hire / rental car comparison: airport and local-depot pick-ups, the big comparison sites and rental brands, for the USA, UK, Europe and worldwide. Repo: `Shmorai/shmor-carhiredeals` (local git only so far; private until launch). Status: **building**. Created 2026-10-16.

## Where things are
| What | Where |
|---|---|
| Card on shmor.ai, search keywords, **comparison sites + rental brands ("providers")**, referral links, SEO defaults | `shmor-site.json` |
| Pages (1 JSON file = 1 Google landing page) | `content/` (`home.json` = homepage, `content/airport-car-hire/lax.json` → `/airport-car-hire/lax/`) |

| Design: styles | `assets/site.css` (kit defaults at the top; **CarHireDeals theme** block at the bottom) |
| Generated output (don't edit by hand) | `index.html`, `*/index.html`, `sitemap.xml`, `robots.txt`, `404.html`, `search/`, `search-index.json` |

## Design
"Open road": white pages, Sora (headings) + Inter, midnight navy #0B1530 (top bar, hero, footer), electric blue #2F6BFF / #1C52E0 (logo, buttons, links), signal amber #FFB020 (search-card border, highlights, dashed "road markings" under the hero and above the footer), green #0E9F6E (ticked-off sites). Logo = blue rounded square with a white car front, amber headlights and amber road dashes + "CarHire**Deals**" + "by Shmor.ai" pill. Header "Find a car" button.
- **Search form**: pick-up location, pick-up date + time, drop-off date + time, driver age, "Sites in" USA $ / UK £ / Europe € (defaults: a week from today for 3 days at 10:00; region from the page, the URL or the browser language).
- **Compare results** (`compare` block + `site.js`): two lists, comparison sites and rental brands, filtered by region. Providers with a `url` template open **with the trip filled in** and are listed first; others open their own site ("enter your trip there"). Clicked rows get ticked off. Under-25 / 70+ drivers see an age note.
- Deep links checked 2026-10-16: KAYAK (`/cars/{qp}/{in}-{h1}h/{out}-{h2}h` on .com, .co.uk, .ie; IATA codes work best) and Expedia (`carsearch?locn=&date1=&date2=&time1=&time2=`; US dates MM/DD/YYYY, UK/IE DD/MM/YYYY; times like 600AM/900PM) prefill correctly. Rentalcars.com, Discover Cars, Priceline and Auto Europe need their own location IDs, so they open on their homepage; Skyscanner showed a bot check, so it's a plain link too. Brand homepages (.com and .co.uk) all checked loading.
- Cards and pages show **no prices or ratings** (network rule: no invented prices/deals). Badges are editorial ("Most popular", "Sun favourite").
- Photos: free-licence Unsplash (already used elsewhere in the network) plus Wikimedia Commons (CC0 / CC BY / CC BY-SA / public domain), credited with author + licence and linked to the file page. Mobile checked at 375px: no horizontal scroll on any page.

## Referral links
When a programme approves you (Rentalcars.com, Discover Cars, Expedia, KAYAK, brand programmes on Awin/CJ/Impact…), add the link to `"links"` and set `"link": "<slug>"` on that provider in `"providers"`: all its buttons then go through shmor.ai/go/ (tracked, `rel="sponsored"`), but lose the prefilled trip, because /go/ takes one fixed URL. For per-region links use `"url": { "us", "uk", "eu" }` in the link. Rebuild, sync the master, commit both repos.

## Commands (run here)
```bash
node tools/build.js           # rebuild after ANY change to content/, templates/ or shmor-site.json
node tools/serve.js 4021      # local preview (preview config "carhiredeals")
```
After changing `shmor-site.json`, also run `node tools/sync-network.js` in `../../shmor-ai`.
